# M8 工作区修改与测试工具

## 范围与接口

在 M7 的 `workspace_tools/` 中扩展 `WorkspaceTools.execute(ToolRequest)`，统一路由只读操作、`apply_patch`、`status`、`diff` 和 `run_tests`。请求新增可选 `patch` 文本；结果新增可选 `details`，未使用时保持 M7 JSON 格式。修改范围由可信宿主 `WritePolicy` 决定，示例默认只允许 `todo_app/`，请求和 CLI 不能扩大范围。

## 补丁

采用严格的 UTF-8 unified 文本 diff，支持常规文件修改、创建和删除。按 hunk 行号及原内容精确匹配，不做模糊定位。只处理 `---/+++` 和计数明确的 hunk；可接受 Git 的文本前导信息，但不允许重命名、复制、二进制或权限变化。默认补丁不超过 256 KiB、20 个文件，单个结果文件不超过 M7 的 256 KiB 上限。

复用 M7 相对路径、Git 元数据及 Windows 路径检查；检查所有已存在祖先、符号链接、junction，拒绝硬链接目标。先校验所有路径、旧内容和结果大小，再写文件。单文件使用同目录临时文件和原子替换；普通写入失败时回滚已修改文件，回滚不完整必须明确报错。进程崩溃恢复留待后续阶段；工具仍面向操作期间稳定的受信任工作区。

## 状态、Diff 与测试

状态查询不暂存或提交代码。Diff 以 M5 固定提交为参照，包含候选已提交、已暂存、未暂存及可读取的未跟踪文本；保留 BOM 和末尾无换行标记，跳过过大或非文本文件时记录提示。Git 查询及测试调用前检查候选文件树，拒绝链接/重解析点、硬链接、嵌套 Git 元数据及超出条目上限的工作区。Git 调用禁用外部 Diff、textconv 与 fsmonitor，使用参数列表，并限制执行时间和返回输出。

固定测试复用 `ContainerTestRunner`，不接受命令、镜像、挂载或超时参数。`details` 保留运行标识、镜像、测试状态、真实退出码、耗时及日志路径。pytest 非零退出仍是完成一次测试调用；超时和基础设施故障为错误。CLI `run-tests` 返回真实退出码、超时 124 或错误 2。

## 验收

测试合法修改/创建/删除、原内容不符及多文件整体拒绝、写入回滚、路径越界、链接与范围拒绝、补丁/文件/输出限制、Git 状态/Diff、固定测试结果和 CLI。真实演示从固定 Todo 基线创建临时工作区，应用预设 404 修复、查看 Diff、在 M6 容器得到五项测试通过并保留证据；随后恢复演示改动并用 M5 清理。根文档在验收后标记 M0–M8 完成，下一步 M9。
